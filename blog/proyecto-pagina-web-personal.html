Proyecto: Página Web Personal

Introducción

La idea de desarrollar una página web personal se originó mucho antes de comenzar este proyecto. Desde hace tiempo tenía pensado contar con un espacio propio en Internet en el cual pudiera presentarme ante el mundo, compartir mis habilidades y mostrar los trabajos que fuera realizando a lo largo de mi formación académica y profesional.

Considero que tener un sitio web independiente es una herramienta útil para establecer contactos, ya que basta con compartir una dirección URL para que otras personas puedan conocerme y ponerse en contacto conmigo. También puede funcionar como portafolio para futuros empleadores, permitiéndoles conocer mis proyectos.

Sin embargo, aunque tenía esa idea, no había encontrado la motivación suficiente para llevarla a cabo. Esto cambió cuando, en la materia de "Competencia Digital", se nos dio la oportunidad de realizar un proyecto de nuestra elección. Aproveché esa oportunidad para convertir una idea en realidad.

De esa forma se originó este sitio web, desarrollado únicamente con HTML y CSS. Este proyecto me permitió adquirir nuevos conocimientos, ponerlos en práctica y familiarizarme con distintas herramientas utilizadas en el ámbito del desarrollo web.

En este artículo documentaré el proceso que llevé a cabo, desde la preparación del entorno de trabajo y el aprendizaje de los fundamentos necesarios hasta el desarrollo y la publicación del sitio. Mi intención es que esta experiencia pueda servir como referencia para otros estudiantes interesados en crear su propia página web.

Preparación del entorno de desarrollo

Instalación de Fedora Linux

Antes de comenzar con el desarrollo del proyecto, fue necesario preparar un entorno de trabajo adecuado. Para ello, decidí utilizar Linux como sistema operativo, aunque opté por explorar distintas distribuciones antes de elegir una.

Primero probé Ubuntu, pero tuve diversos problemas que interrumpían constantemente mi ritmo de trabajo. No pude determinar si esos inconvenientes se debían al sistema operativo en sí o a las características de mi computadora, puesto que uso una Lenovo ThinkPad T440p, la cual tiene ya varios años de antigüedad.

Después utilicé Linux Mint, una distribución que me dejó una muy buena impresión por su funcionamiento y apariencia, bastante familiar para mí debido a su parecido con Windows. Sin embargo, noté que incluía algunas herramientas y opciones adicionales que realmente no necesitaba para el proyecto y que terminaban convirtiéndose más en una distracción que en un apoyo.

Finalmente, usé Fedora, que funcionó correctamente desde el primer día. Su apariencia y funcionamiento general me permitieron concentrarme en el aprendizaje y desarrollo del proyecto sin las interrupciones que había experimentado anteriormente con las otras distribuciones. Por estas razones, elegí Fedora como mi sistema operativo de trabajo.

Para instalarlo, descargué la imagen ISO del sistema desde el sitio web oficial y seguí las instrucciones proporcionadas para verificar su autenticidad e integridad. Después, desde Windows, utilicé un programa llamado Rufus para preparar una memoria USB de instalación.

Por último, instalé el sistema operativo en una unidad M.2 independiente del SSD donde tenía instalado Windows, de tal forma que pudiera disponer de ambos sistemas por separado.

Una vez instalado Fedora y comprobado su correcto funcionamiento, contaba con una base estable para comenzar a instalar y configurar las herramientas necesarias para el desarrollo de mi proyecto web.

Instalación de Visual Studio Code

Para escribir y editar el código del proyecto, decidí utilizar Visual Studio Code, un editor de código recomendado tanto por The Odin Project como por numerosos desarrolladores.

Después de comenzar a utilizarlo, comprobé que era una herramienta adecuada para mis necesidades, ya que me permitía trabajar de manera cómoda y concentrarme en el desarrollo del proyecto sin complicaciones innecesarias.

Para instalarlo en Fedora Linux, seguí las instrucciones proporcionadas en la documentación oficial de Visual Studio Code para Linux .

Una vez instalado, lo utilicé para abrir los archivos del proyecto directamente desde la terminal mediante el comando code, así como para escribir y editar el código HTML y CSS de mi página web.

Instalación de Chromium

Para comprobar el funcionamiento de mi página web, necesitaba un navegador basado en Chromium, ya que Google Chrome es uno de los navegadores más utilizados. De esta manera, podía asegurarme de que el sitio se visualizara y funcionara correctamente en un entorno similar al utilizado por muchos usuarios.

Elegí Chromium porque prefería utilizar una alternativa de código abierto, sin algunas de las integraciones y servicios propios de Google Chrome.

Su instalación fue sencilla, ya que únicamente tuve que buscarlo en la tienda de aplicaciones de Fedora e instalarlo desde allí. Posteriormente, lo utilicé para visualizar mi página web y comprobar los cambios que realizaba durante su desarrollo.

La terminal de Linux y Git

Antes de comenzar a trabajar en el proyecto, dediqué parte de mi tiempo a familiarizarme con la terminal de Linux. Para ello, utilicé como referencia el material educativo The Unix Shell de Software Carpentry.

Mi objetivo no era aprender todas las posibilidades que ofrece la terminal, sino adquirir los conocimientos fundamentales para desenvolverme en el entorno de desarrollo. Por esta razón, me concentré en comprender su funcionamiento y aprender los comandos necesarios para trabajar con archivos y directorios.

También comencé a estudiar Git, utilizando como referencia el libro Pro Git y el artículo How to Write a Git Commit Message . Estos recursos me ayudaron a familiarizarme con el control de versiones y las convenciones para escribir mensajes de commit.

No dediqué demasiado tiempo a esta etapa de estudio, ya que mi intención era comenzar a trabajar cuanto antes y continuar aprendiendo mediante la práctica. A lo largo del proyecto, fui reforzando estos conocimientos conforme necesitaba utilizar nuevas herramientas y comandos.

Aprendizaje de los fundamentos

The Odin Project

Al comenzar mi aprendizaje sobre desarrollo web, no tenía claro qué curso utilizar. Consideré distintas alternativas, entre ellas freeCodeCamp y The Odin Project, mientras buscaba el recurso que pudiera ofrecerme la mejor formación posible.

Sin embargo, después de investigar distintas opciones, comprendí que no existe un curso perfecto y que lo verdaderamente importante era aprender los fundamentos del desarrollo web y ponerlos en práctica. Con esto en mente, finalmente me decidí por The Odin Project.

Una de las características que más me gustaron de este curso fue su metodología de enseñanza. Además de proporcionar las lecciones, ofrece enlaces a documentación y recursos externos que permiten profundizar en los temas estudiados. También incluye ejercicios prácticos para aplicar los conocimientos adquiridos.

Esta combinación de teoría, investigación y práctica me resultó especialmente útil, ya que me permitió desarrollar una mejor comprensión de los conceptos y comenzar a utilizarlos por mi cuenta. Por estas razones, considero que elegir The Odin Project fue una buena decisión para iniciar mi formación en desarrollo web.

HTML

Para comenzar a aprender HTML, estudié las lecciones correspondientes al bloque HTML Foundations de The Odin Project, así como los recursos adicionales proporcionados al final de cada lección.

Durante esta etapa, aprendí que HTML es un lenguaje de marcado utilizado para definir la estructura y el contenido de las páginas web. Estudié el funcionamiento de las etiquetas, los elementos y sus atributos, así como la estructura básica que debe tener un documento HTML.

También aprendí a organizar contenido mediante encabezados, párrafos y listas, además de utilizar enlaces para conectar diferentes páginas y recursos. Por último, estudié cómo incorporar imágenes y trabajar con rutas relativas y absolutas.

Estos conocimientos fueron fundamentales para desarrollar mi página personal, ya que me permitieron organizar su contenido en distintas secciones, incorporar una fotografía, agregar enlaces de contacto y estructurar la información de los proyectos que quería presentar.

CSS

Después de estudiar HTML, continué con las lecciones del bloque CSS Foundations de The Odin Project, así como los recursos adicionales proporcionados al final de cada lección.

Durante esta etapa, aprendí que CSS es un lenguaje de hojas de estilo utilizado para controlar la presentación visual de las páginas web. Estudié cómo vincular un archivo CSS con un documento HTML, utilizar selectores y aplicar propiedades para modificar aspectos como los colores, las fuentes, los tamaños y los bordes de los elementos.

También estudié el funcionamiento de la cascada, la especificidad y la herencia, conceptos que permiten comprender cómo se aplican las distintas reglas de estilo. Además, aprendí sobre el modelo de caja, las propiedades margin y padding, las diferencias entre elementos de bloque y en línea, y el uso de las herramientas de inspección del navegador para examinar y probar estilos.

Estos conocimientos me permitieron definir la apariencia de mi página personal, establecer una paleta de colores, seleccionar tipografías y ajustar los espacios entre los distintos elementos. También fueron fundamentales para diseñar las tarjetas de los proyectos y las secciones de contacto y apoyo, manteniendo una presentación visual consistente.

Flexbox

Después de estudiar los fundamentos de CSS, continué con las lecciones del bloque Flexbox de The Odin Project, así como los recursos adicionales proporcionados al final de cada lección.

Durante esta etapa, aprendí que Flexbox es un sistema de diseño de CSS que permite organizar y distribuir elementos dentro de un contenedor. Estudié el funcionamiento de los contenedores flexibles y sus elementos, así como las propiedades que permiten controlar su tamaño y distribución.

También aprendí sobre los ejes principal y transversal, y cómo estos cambian dependiendo de la dirección de los elementos. Además, estudié propiedades como flex-direction, justify-content y align-items, que permiten controlar la orientación y alineación de los elementos dentro de un contenedor.

Estos conocimientos me resultaron especialmente útiles para organizar los elementos de la sección de contacto de mi página personal. Mediante Flexbox, pude distribuir los enlaces verticalmente, centrarlos y establecer un espacio uniforme entre ellos, manteniendo una presentación consistente en distintos tamaños de pantalla.
